# Rien de tout cela n'est versionné : `corpus/fetch.sh` le télécharge dans
# `corpus/cache/`, ignoré par Git, et refuse tout écart avec ce manifeste.
# Une section par corpus ou moteur, une clé `nom = valeur` par ligne.
#
#   source   archive (tar gzip, empreinte SHA-256), git (commit figé),
#            deb (paquet Debian dépaqueté sans installation) ou maven (jars)
#   url      adresse de l'archive, du dépôt ou du paquet
#   version  date de publication constatée (corpus), version figée (moteur) ;
#            le banc refuse un moteur d'une autre version
#   sha256   empreinte de l'archive ou du paquet
#   commit   commit complet (source git)
#   jar      adresse d'un jar puis son empreinte SHA-256, une ligne par jar
#            (source maven) ; le pilote Java du banc est compilé contre eux
#   pattern  motif des fichiers de graphe
#   count    nombre exact de fichiers attendus pour ce motif
#   licence  licence constatée, et où
#   node_size  taille donnée à chaque nœud à l'import (GraphML), en centièmes
#              de pixel : le format n'en porte aucune
#   imported   nombre de fichiers que l'import doit convertir (ELK) ; les
#              autres sont refusés pour une raison que `check-corpus` affiche
#
# Les licences ont été lues le 2026-10-10 (corpus) et le 2026-10-11 (moteurs).
