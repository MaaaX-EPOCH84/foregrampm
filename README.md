# ForegramPM

Gestion de projet en fichiers texte, pilotable par une IA : diagrammes
UML et Merise écrits en texte, rendus en images à intégrer dans la
documentation.

Le nom : *foreman* (chef de chantier) + *diagram*, et *PM* pour
*project management*.

Projet en cours de cadrage — voir `docs/genese.md`.
